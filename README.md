# Система бронирования столиков ресторана

## Веб-приложение на Django для онлайн-бронирования столиков в ресторане. Пользователи могут создавать и управлять своими бронированиями, а сотрудники ресторана — просматривать и оформлять бронирования по телефону.

## В проекте реализовано приложение reservations:
### в модуле models описаны модели:
* бронирования столиков (Reservation);
* столиков ресторана (Table);
* настроек сайта ресторана (SiteContent);
* кастомного пользователя (CustomUser);
* Обратной связи (Feedback)
### в модуле views реализованы классы для:
* создания бронирования;
* просмотра списка будущих бронирований;
* просмотра истории бронирований;
* просмотра деталей бронирования;
* редактирования и удаления бронирования;
* просмотра занятости столиков на выбранную дату;
### в модуле forms реализованы формы создания и редактирования бронирований;
### в модуле services реализованы вспомогательные функции для получения настроек сайта;
### в модуле context_processors реализована передача глобальных настроек ресторана во все шаблоны;
### в модуле urls настроены маршруты приложения;
### реализована система разграничения прав доступа на основе Django Groups и Permissions;
### реализована кастомная management-команда для автоматического создания группы менеджеров и назначения необходимых разрешений.
## Роли пользователей
### Пользователь
* может создавать бронирования;
* может просматривать только свои бронирования;
* может редактировать и удалять только свои бронирования.
### Менеджер
* может просматривать все бронирования;
* может создавать бронирования по телефону;
* телефонные бронирования автоматически помечаются специальным флагом.
### Администратор
* осуществляет управление системой через Django Admin.
## Установка
1. Клонируйте репозиторий
```
1. git clone git@github.com:LeslieShmit/diploma_work.git
```
2. Установите зависимости
```
2. poetry install
```
3. Создайте файл .env

Создайте файл .env в корне проекта и заполните его по примеру файла .env.sample.

4. Выполните миграции
python manage.py migrate
5. Создайте группу менеджеров
python manage.py create_managers_group
6. Создайте администратора
python manage.py createsuperuser
7. Запустите сервер
python manage.py runserver

 После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000

Запуск проекта через Docker Compose

## Проект использует Docker Compose для запуска сервисов одной командой.

### В состав проекта входят:

* Django-приложение;
* PostgreSQL.
## Подготовка к запуску

Установите Docker Desktop и запустите его.

## Запуск проекта

Выполните команду:

docker-compose up -d --build

После запуска приложение будет доступно по адресу:

http://localhost:8000
## Дополнительные команды

* Просмотр запущенных контейнеров:
docker-compose ps

* Просмотр логов: docker-compose logs

* Остановка контейнеров: docker-compose down -v
